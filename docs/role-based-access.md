# Role-Based Access for Services

This document outlines the permissions for different user roles regarding the management and visibility of services.

## Garage Owner
- **Create**: Can create new services.
- **Edit**: Can edit all details of existing services.
- **Deactivate**: Can deactivate or activate services.
- **View**: Can view all services, including their detailed profiles and financial data.

## Workshop Manager
- **Create**: Can create new services.
- **Edit**: Can edit details of existing services.
- **Deactivate**: Can deactivate or activate services.
- **View**: Can view all services and their profiles.

## Receptionist
- **View**: Can view all active services.
- **Use**: Can use active services when creating new bookings for customers.

## Mechanic
- **View**: Can only view the details of services that are linked to job cards assigned to them.

## Inventory Officer
- **View**: Can view services only when there is a need to link inventory parts to a service.

## Accountant
- **View**: Can view service details, particularly pricing (labor cost) and revenue information, for financial reporting and analysis.

## Customer
- **View**: Can view all active services in the customer portal, helping them understand the services offered.
